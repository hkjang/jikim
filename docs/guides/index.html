JIKIM DOCUMENTATION

운영을 위한 가이드

v0.2.6에서 검증한 범위와 운영자가 확인해야 할 보안 경계를 한국어로 설명합니다.

ADMIN

관리자 가이드

최초 기동, 사용자, Keycloak, AI, 승인과 키 정책을 설정합니다.

 USER

사용자 가이드

로그인, Secret 관리, 개인 키 회전과 승인 요청을 설명합니다.

 DEVELOPER

API 가이드

인증 헤더, 응답, 스트리밍 AI와 MCP/API 보안 경계를 다룹니다.

 OPERATIONS

오프라인 설치

SHA-256 검증, docker load, Compose 기동과 상태 확인 절차입니다.

 SECURITY

보안 가이드

마스터 키, 저장 암호화, TLS, 감사, 백업과 사고 대응 원칙입니다.

 COMPATIBILITY

OpenBao 호환성

전체 호환 주장 없이 엔드포인트별 구현 상한과 differential suite 미구현 상태를 공개합니다.

v0.2.6 부트스트랩 계약

서비스는 고정 포트 8080과 네 환경변수 POSTGRES_DSN, BOOTSTRAP_ADMIN, BOOTSTRAP_ADMIN_PASSWORD, ENCRYPTION_KEY를 사용합니다. 자세한 반입 절차는 오프라인 설치 가이드에서 확인하세요.
