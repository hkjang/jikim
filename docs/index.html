자주 묻는 질문

운영 전에는 릴리스 노트와 버전별 구현 프로파일을 함께 확인하세요.

jikim은 폐쇄망에서 운영할 수 있나요?

예. 서비스 이미지는 jikim-v버전.tar.gz로 반입하고 docker load로 적재합니다. 런타임에는 외부 패키지 저장소가 필요하지 않습니다. PostgreSQL과 선택한 사내 연동 대상은 별도로 준비해야 합니다.

OpenBao와 완전히 호환되나요?

아닙니다. v0.1.0은 전체 호환을 주장하지 않는 제한 프리뷰이며 OpenBao differential suite도 아직 없습니다. 기존 클라이언트를 연결하기 전에 사용 API를 별도로 비교 테스트해야 합니다.

환경변수는 몇 개가 필요한가요?

POSTGRES_DSN, BOOTSTRAP_ADMIN, BOOTSTRAP_ADMIN_PASSWORD, ENCRYPTION_KEY 네 개입니다. Keycloak, AI, 승인과 키 정책 같은 운영 설정은 관리자 화면에서 관리하는 구조입니다.

AI에 Secret 평문이 전달되나요?

AI 연동은 메타데이터와 감사 통계를 중심으로 설계하며 Secret 평문을 모델 요청에 포함하지 않는 것을 기본 보안 경계로 둡니다. 운영자는 내부 AI 엔드포인트, 모델, 제한과 스트리밍 정책을 관리해야 합니다.

누가 키를 회전할 수 있나요?

사용자는 활성 개인 키에 회전 권한이 있을 때 자기 키를 회전할 수 있고, 관리자는 전체 개인 키를 관리할 수 있습니다. Transit 키는 관리자 또는 키에 회전 권한을 가진 팀장이 회전합니다. v0.1.0의 승인 워크플로는 키 회전에 적용되지 않습니다.
